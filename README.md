# Kulturex Connect MVP

Kulturex Connect is a cultural commerce MVP for products, services, events, and diaspora marketplace discovery.

## Concept

Kulturex Connect helps buyers discover authentic African and Asian cultural products and services while giving sellers a trusted platform to reach global markets.

## Included

- Landing page
- Marketplace page
- Seller dashboard
- Listings API
- Orders API
- Moderation API
- Prisma schema
- Seed data

## Core Product Features

- Cultural product and service listings
- Seller performance dashboard
- Contact-sharing moderation logic
- Marketplace search/filter UI
- Order and payout workflow foundation

## Tech Stack

- Next.js
- TypeScript
- Prisma
- PostgreSQL
- Zod

## Quick Start

```bash
npm install
cp .env.example .env
npm run prisma:generate
npx prisma migrate dev --name init
npm run seed
npm run dev
```
